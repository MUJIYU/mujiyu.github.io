# 此刻 · 冥想 App UI

基于用户提供的 iOS 原型，实现完整流程的可交互移动端高保真网页。

## 运行

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 `http://127.0.0.1:4173/`。

## 页面范围

- 启动与登录流程。
- 首页：即时情绪选择、冥想/专注/睡眠/呼吸入口、睡前练习横滑、底部导航。
- 冥想：主题列表、练习工具、冥想播放与计时控制。
- 专注：计时、暂停、重置和专注设置面板。
- 睡眠：助眠声音、睡眠故事和睡前放松播放。
- 呼吸：4-2-6 呼吸节奏、3 分钟倒计时、暂停与重新开始。
- 觉察：情绪选择、需要与强度、推荐练习、情绪空间、日记编辑和文章阅读。
- 我的：练习统计、今日回顾与设置。

所有页面使用 393 × 852 iPhone 内容视口，并保留模板提供的设备框、状态栏和键盘运行时。

## 视觉系统

颜色、圆角、间距和字体统一维护在 `src/prototype.css` 的 `.app-shell` 自定义属性中。功能图标来自 Phosphor Icons；自然摄影资产已下载并打包到 `public/assets/app/`，运行时不依赖外部图片服务。

## 验收

- `npm run build`
